# v0.5.0 — Tournaments: teams, formats, skill levels, Today nav, editing

- **Stage machine** on live events: roster → team_formation → teams_locked → matches_set → started, with guarded transitions (`/api/events/[id]/stage`).
- **Team formation**: tile-tap UI (2 taps = doubles team), dissolve/clear, prefill from confirmed partner pairs, singles bulk-add; oc_teams with seed = creation order.
- **Match formats**: single elimination (bracket w/ byes to top seeds, TBD slots created up front, winners auto-advance on score entry), round robin (all pairs), manual (admin picks team vs team). Regeneration supported until scores exist.
- **Tournament run**: start button gates score entry; tabbed event view (Matches / Standings / Players); team standings with points diff; champion banner for completed knockouts.
- **Skill levels** (1–5 dots): optional prompt at registration, Profile self-serve, admin edit in Users tab. Shown in Users, deliberately hidden on event pages.
- **User editing**: inline panel (name/email/skill), disable/re-enable; disabled players hidden from the main list and admin check-in actions.
- **Event editing**: /events/[id]/edit (format locked once teams exist).
- **Today nav**: bottom-nav shortcut to your checked-in live event (IST date preference), falls back to events home.
- **Perf**: 30s warm-instance cache for the everyone_admin flag, parallelized event-page queries, route loading skeletons.
