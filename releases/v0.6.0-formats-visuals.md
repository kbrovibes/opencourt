# v0.6.0 — Format overhaul, visuals, soft delete, UX fixes

- **Soft-delete events**: 🗑 in admin controls (two-tap confirm) sets `deleted_at`; event disappears app-wide (lists, tiny URLs, Today nav) but is recoverable by clearing the column.
- **Team formation is now client-side**: tap tiles to build lineups locally (amber "not saved" list), then one **💾 Save N teams** bulk call (`create_bulk`). Mid-way saves fine; dissolve saved teams individually.
- **Fixed rounds format** (new default suggestion): admin inputs matches-per-team; circle-method schedule guarantees everyone plays exactly N group matches, no surprise quarterfinals. Round robin now uses the same scheduler (full N-1 rounds).
- **Playoffs generator**: for group formats, once all group matches are scored — "Final (top 2)" or "Semis + Final (top 4)" appended from standings (1v4/2v3); winners auto-advance.
- **Round naming fixed**: knockout names (QF/SF/Final) only for bracket matches; group matches are plain "Round N"; bye teams labeled "⤴ bye".
- **Overview tab** (default when running): progress bar, knockout bracket columns with 👑 champion column, group results matrix (win/loss colored score grid), top-3 podium.
- **Completed-event banner**: closed events open with champions/runners-up + stat tiles (players, matches, points) — snobaddy closed-session style.
- **Dark-mode native controls fixed** via `color-scheme` (selects/date pickers no longer white).
- **Skill defaults to 3** (DB default + backfill); registration shows the dots preset for adjustment.
