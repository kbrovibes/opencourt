# v0.1.0 — Scaffold

Initial project scaffold, heavily derived from snobaddy:

- Identical tech stack: Next.js 16 (App Router), React 19, Tailwind 4, Supabase (shared project, `oc_`-prefixed tables), Vercel.
- Identical theme system: stone light palette + near-black dark palette, `opencourt:theme` localStorage key, system-mode aware.
- `src/proxy.ts` auth guard with `?next=` deep-link preservation for `/e/CODE` short links.
- Auth: Google OAuth (primary) + email/password (secondary), auto-creates `oc_players` on first login, claims manually-created players by email match.
- Bottom nav: Events (home), Users (admin only), Profile.
- Changelog discipline carried over: `CHANGELOG.md` + `releases/` + pre-commit guard.
