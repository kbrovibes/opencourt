# v0.4.1 — Password-login redirect fix

- After email/password sign-in, use `window.location.assign(next)` instead of `router.push(next)`. Client-side navigation raced the freshly-set Supabase auth cookies, bouncing users to /welcome and dropping the `?next=` deep link (e.g. from a shared `/e/CODE` URL). A full navigation guarantees cookies are on the server request.
- `scripts/cleanup-test-data.mjs`: removes the overnight-validation test events/players/auth users.
