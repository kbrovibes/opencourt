# v0.2.0 — Schema + API layer

- `supabase/migrations/20260801_init_oc.sql`: oc_settings (everyone_admin kill switch, seeded true), oc_players, oc_events (short_code tiny URLs, draft/live/completed/cancelled, singles/doubles, checkin_opens_at), oc_event_players (registration + check-in + partner in one row; waitlist computed from registration order), oc_matches.
