# v0.3.0 — Events UI

- Events home: Ongoing & Open / Drafts (admin) / Past sections with reg counts.
- Create Event form (admin): name, date, time, singles/doubles, max players, draft/live, check-in open time, location, notes.
- Event detail: info card, tiny-URL share button (Web Share API + clipboard fallback), admin status controls (go live / complete / back to draft / reopen / cancel), register / withdraw / check-in / undo actions, doubles partner picker (mutual-confirm model), roster with Registered / Waitlist / Checked-in states.
- Matches: admin creates from checked-in players, score entry marks winner, standings (W/L) computed from completed matches. Singles + doubles aware.
- /e/[code] tiny-URL redirect route.
